404 Status Code Test

Current Behavior (Status 200)

When you navigate to a non-existent route like /invalid-page:

  • ✅ Shows the 404 page correctly
  • ❌ HTTP status code is 200 (OK)
  • ❌ Search engines might index these pages

Desired Behavior (Status 404)

What should happen for invalid routes:

  • ✅ Shows the 404 page correctly
  • ✅ HTTP status code is 404 (Not Found)
  • ✅ Search engines won't index these pages
  • ✅ Proper error handling for monitoring/analytics

Solution

The server-side code needs to be updated to return proper HTTP status codes:

  1. Check if the route is a valid UI route
  2. If valid: serve index.html with status 200
  3. If invalid: serve index.html with status 404
  4. For API routes: return JSON error with status 404

See 404-STATUS-GUIDE.md for implementation details.

How to Check Status Codes

  1. Open browser Developer Tools (F12)
  2. Go to the Network tab
  3. Click on one of the test links above
  4. Look for the main document request
  5. Check the Status column
