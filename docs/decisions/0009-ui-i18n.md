# 0009: UI text lives in Paraglide

Status: accepted, 2026-11

## Decision

- All web UI text is Paraglide messages (`ui/packages/frontend/messages/en.json`, base locale `en`). Parameter labels and help texts are keys `param_<name>_label` / `param_<name>_help` in the same file.
- The firmware keeps no UI-only metadata: no labels, help texts, sections or order. `ParamDef` holds key, type, limits, default and reboot flag; `/api/parameters` sends those plus `requiresReboot`.
- Enum option labels stay in firmware: `Choice::OPTIONS` is the vocabulary `set_from_str` parses.
- OLED text stays in firmware (ADR 0007).
- `scripts/check-i18n.mjs` (run by `pnpm lint`) fails on English typed into Svelte templates or attributes.

## Consequences

- Only `en` exists. Adding a language means a new `messages/<locale>.json`; a locale switch in the UI is not built yet.
- The Paraglide compile step fetches the message-format plugin from a CDN (`project.inlang/settings.json`). Offline builds need it cached.
