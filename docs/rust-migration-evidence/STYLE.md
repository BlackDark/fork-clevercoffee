# Style card

Rules these docs follow. Read time: 1 minute.

1. Open with a 3-line verdict, then the evidence.
2. One idea per sentence. Aim under 20 words.
3. One topic per section. One line per bullet.
4. Write headings that name the finding, not the topic.
5. Put each fact in one place. Link to it, never repeat it.
6. Use tables for status, checklists for actions, and no paragraphs of three.
7. Mark every claim: ✅ works · ⚠️ partial · ❌ broken · ❓ unverified.
8. Cite evidence inline as `branch:path` or a commit hash.
9. Use everyday words. Expand each acronym once, at its first use.
10. Use active voice and present tense.
11. Use ❓ rather than a guess. An unproven claim is written as unproven.
12. Leave whitespace between sections. No walls of text.
13. State purpose and read time at the top of every doc.
14. Cut marketing language and history narration.
15. Keep a doc under 150 lines. Cut anything that changes no decision.
